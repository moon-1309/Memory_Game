# Memory_Game

Welcome to the Pokémon Memory Game! 🧠⚡️

Get ready to test your memory and matching skills in this classic game, beautifully styled with your favorite Pokémon characters! 🌟 A hidden array of cards awaits—your mission is to flip them, find the matching pairs, and clear the board. 🏆

Each turn is a chance to unlock a pair, but choose wisely! Can you remember the location of each Pokémon and match them all before your mental energy runs out? 🤔 Click to flip your first card and let the challenge begin! 💪
